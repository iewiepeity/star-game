# 立繪圖檔放這裡

程式碼已經把路徑訂好了，圖畫好之後**只要用下面列的檔名存進這個資料夾，畫面就會自動顯示，不需要改任何程式碼**。
在圖檔就位之前，畫面會自動顯示原本的文字頭像／占位框，不會出現壞掉的圖示。

## 玩家立繪（依性別，見 `src/data/portraits.js`）

| 檔名 | 對應 |
|---|---|
| `player-female.png` | 性別選「女性」 |
| `player-male.png` | 性別選「男性」 |
| `player-nonbinary.png` | 性別選「非二元」 |
| `player-default.png` | 選「自訂」或還沒選擇性別時的預設圖 |

會出現在：角色建立畫面（STEP 1 性別選擇旁的預覽框）、房間畫面左上角的玩家頭像。

## 人物立繪（依 NPC id，見 `src/data/npcs.js` 的 `portrait` 欄位）

| 檔名 | 對應 |
|---|---|
| `jiqing.png` | 紀晴（電臺主持人） |

會出現在：人物檔案 App 的大頭照與左側人物列表、手機通訊錄的聯絡人頭像。

之後新增 NPC 時，在 `src/data/npcs.js` 那個人物的資料裡加一行 `portrait:"./assets/portraits/<新檔名>.png"` 即可，不用動畫面程式碼。

## 圖檔規格建議

- 格式：PNG（需要透明背景時）；也可以用其他格式，只要把 `src/data/portraits.js` 或 `src/data/npcs.js` 裡對應的副檔名改掉即可。
- 尺寸：目前的頭像框都是接近正方形或直式小卡（顯示時會用 `object-fit:cover` 裁切置中），建議準備直式且主體置中的圖，裁切起來比較不會切到臉。
- 檔案大小：跟 `assets/` 底下其他背景圖一樣，建議壓縮到合理大小（現有背景圖大約 30～120KB），避免拖慢載入。
