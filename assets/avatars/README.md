# 玩家立繪與服裝素材

四種玩家外型各有十五套同人物造型，檔名格式為 `<avatarId>-<outfitId>.webp`。其中十套擴充服裝共有 40 張獨立新立繪，不再借用舊服裝素材：

- `raven`：夜櫻系黑髮女性立繪
- `sunny`：暖杏系女性立繪
- `noir`：夜墨系男性立繪
- `sage`：春茶系男性立繪
- `newcomer`：新人私服
- `practice`：練習服
- `audition`：試鏡造型
- `stage`：舞台造型
- `gala`：典禮禮服
- `casual`：週末休閒套裝
- `street`：街頭機能造型
- `classic`：經典試鏡正裝
- `vocal`：錄音室舒適穿搭
- `variety`：綜藝亮色套裝
- `cinema`：演員質感套裝
- `editorial`：時尚編輯造型
- `premium`：精品活動禮服
- `host`：典禮主持正裝
- `icon`：個人標誌造型

素材為透明背景 WebP，固定 512×1024 畫布。遊戲採完整立繪切換而非即時疊衣服圖層，讓服裝可連同髮型一起變化，也避免不同身形或生成誤差造成領口、手臂與腰線錯位；資料與加成定義集中於 `src/data/wardrobe.js`。

`silver-*` 是銀灰角色的 NPC 素材，不屬於玩家可選外型；她必須經由正式相遇事件加入 `knownPeople` 後，才可出現在人物檔案與通訊錄。

`thumbs/` 是由完整立繪產生的 160×320 低負擔版本，專供創角選單、衣櫃清單與 HUD 使用。完整立繪只用於當前人物的大型預覽，避免同一畫面一次解碼多張大型透明圖片。
