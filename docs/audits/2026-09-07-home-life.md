# 第一階段居家生活補驗

基準：main 的 PR #49 合併提交 `6c84bd4a6dbaea4eb5d4ff31a06d308a698e2ab7`。

## 查核與修正

| 項目 | 初版缺漏 | 本次結果 |
| --- | --- | --- |
| 手動製作／作客 | 確認按鈕遺失配方、NPC 與活動 | 保留完整安排資料，測試實際點擊 handler 到結算 |
| 家具五槽與紀念展示 | 僅管理面板更新，住處未更新 | 共用 canvas 合成來源，背景、家具與坐姿前景同步更新 |
| 作客 NPC | 外部預約缺少 home 地點，場景無人物 | 受邀人物當日出現在家中，翌日／取消／交惡離開 |
| 行程與目標 | 核心行動 ID 不合法、未計入生活 | 使用 personal_task 與 home_host／home_craft taskKind；讀檔遷移 |
| 排程衝突 | 重複邀人、材料超額安排、殘留 NPC 預約 | 材料預留、同週限制、取消與換週清理；職涯與助手保留約定 |
| 手作與送禮 | 引用不存在的能力；指定存檔仍改全域關係 | 接現有能力；隔離指定遊戲，防重播與櫃存上限 |
| 鑰匙 | 失效後可能隨關係回升而自行生效 | 關係事件即時標記失效，玩家重新交付前不恢復 |
| 敘事與存檔 | 人物代稱、活動不一致；未限制成品品質等資料 | 人物及活動校正、入圍區分得獎、限縮不可信存檔資料 |
| 原有 E2E | addInitScript 每次重載覆寫 fixture | 僅首次建立存檔，新增手動製作與作客案例 |

## 驗證

- 原有 479 項 Node 測試通過，另新增 13 項居家回歸測試。
- 使用本機 canvas 執行實際家具合成程式，檢查五個槽位的渲染預覽與 25 個家具圖層更新。這不是瀏覽器端驗收。
- `npm run check` 已通過（格式、lint、內容、492 項 Node 測試、五年模擬、世界反應、素材、PWA 與 build）。
- 瀏覽器驗證未完成：`npx playwright install chromium` 遭逾時及 502，未能安裝 Chromium；桌機／手機 E2E 需在 CI 或具有瀏覽器的環境完成。不得繞過發行門檻直接部署。
