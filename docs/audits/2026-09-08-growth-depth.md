# 養成深化 1～5

Pixel 0.21.0 / Core 1.44.0。以 6791cf26e6d43925b04594cb4dfa81c92326ea78 為修改前基準。

## 實作與入口

1. 九類訓練突破永久保存技巧資格。相關類別的正式試鏡多出技巧選項，基礎判定加成高於穩健路線，仍受身體狀態和錄取率上限影響。行程卡顯示已掌握技巧。不是只有提高能力數字，也不保證錄取；未解鎖或錯類別的偽造選項會被拒絕。
2. 新續作原班回歸沿用基本工期；加薪 25% 需多一天宣傳；創作主導保留原報酬、多一天打磨，專業熟練時提高成品品質、準備不足則扣分。新作品品質納入各次實際工作時的相關能力、健康、心情與疲勞。舊邀請與進行中合約不追加義務；完成作品與同日工作防止重複結算。
3. 第九週起，行程表的每週目標可選彈性、作品、商業或生活重心。第二年作品目標改用真正的製作日；第三年有合作班底、第四年有轉型留白、第五年有作品與重要的人。年度特別目標有不同完成條件，不只更名。週初選擇、行動後鎖定；仍使用原補助金額，每週只領一次，已簽約者的聲望獎勵對應所選重心。
4. 穩定伴侶需要至少一類共同經歷，訂婚和婚姻至少兩類。支持、私下談心、工作交流／合作、履約都可留下足跡；相同經歷不靠重複次數充數。既有傾聽／履約記錄可銜接，既有戀愛階段不降級。共同回憶面板與關係進展說明提供自然語言回饋，不公開好感數字。
5. 學費為第 1～8 週七折、9～10 週八折、11～12 週九折、13 週起原價。行程表持續說明，8、10、12 週特別預告下週變動。救急短工與其他非訓練成本不變。

## 驗證範圍

只執行改動相關單元／整合測試，不跑全套 check 或五年模擬。78 項相關測試通過（含 15 項新規則與像素流程案例）；修改的 JS/MJS 經 ESLint，並重新建置離線包與檢查版本一致性。
