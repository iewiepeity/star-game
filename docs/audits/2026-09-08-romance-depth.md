# 戀愛日常與共同生活改善（1～6）

日期：2026-09-08  
基準：4550451aaa2a829186123ea4459c8ae0dfe40ae9  
版本：Pixel 0.22.0／Core 1.45.0

## 本次範圍

1. 九位可攻略角色各新增四階段專屬場景，共 36 段、108 個相處風格分支。未開放與隱藏路線的解鎖條件不變。
2. 新增文本以具體動作、玩笑與害羞呈現戀愛，另重寫五段常見共用日常的開場與三種結果，保留場景與選項 ID。
3. 玩笑、安靜陪伴、坦白自己的需要會有角色專屬結果，並記住相處風格，於後續專屬場景回應；沒有唯一必選答案。
4. 日常的實際選擇可留下 care/private/work/reliability 羈絆。舊的有效日常記憶可推導羈絆，不新增數值獎勵。負面或未知選項不算。承諾事件引用已有的共同記憶，不編造歷史。
5. 伴侶日常提供暱稱與牽手、擁抱、晚安吻。每次碰觸仍要選擇，同意不跨次自動沿用；改選聊天有相同好感／信任增量，不記成接受碰觸。
6. 結婚登記不再自動公開。可選暫不辦儀式、親友小婚禮，公開設定獨立。分手可記錄疏於相處、方向差異、失信傷害；先談原因，再於後續週次實際支持、談心／交流或履約，確認後才可能重新認識，不直接復合。

## 相容與防重放

- 舊存檔的婚姻、公開狀態與已讀劇情保持原狀；無儀式欄位的舊婚姻標為 legacy，不推測過去婚禮細節。
- 尚未作答的舊結婚邀請改用登記／儀式分開的新文案；eventHistory 不重寫。
- 新舊日常使用同一場景解析器進行選擇驗證與存檔正規化；已排入的舊日常不因關閉新邀請而消失。
- 日常 revision、週次和 eventHistory 防止重複領取；婚禮不能重複完成；每次分手建立新的修復階段。
- 修復不能用當週按兩次、單純等待、錯誤類型的互動或修復開始前已完成的承諾代替。
- 舊 broken 關係若無原因，提供重新談生活／相處差異的路徑；不直接假設已經修復。
- 這次沒有新增 cookies、外部服務、第三方腳本或追蹤。
