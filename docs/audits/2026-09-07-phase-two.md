## 實作與可玩流程

| 項目 | 實際流程 | 驗收重點 |
| --- | --- | --- |
| 穿搭反應 | 衣櫃試穿／换上既有整套 → 真正交談、作客或赴約 → 人物各自記住造型與場合 → 後續手機提起 | 每人每日一次印象；沒有額外好感刷取，陌生人不會知道私人穿搭記憶 |
| 城市熟客 | 完成咖啡館、排練室、服飾店、公園、錄音室的一日活動 → 熟悉招呼 → 第五次的實際消息 → 排入既有工作／練習行程 → 完成後回收消息 | 進出場景不累積；消息不是免費錄取或作品；機會僅結算一次 |
| 節慶紀念日 | 城市生活日曆 → 選已認識的對象 → 看雙方可用日期 → 邀約／改期／取消 → 實際到咖啡館赴約 → 翌日訊息 | 年度生日、跨年、正式交往紀念；每個場合一次；一天、$300；撞期不會取消原約；跨週恢復 |
| 寵物陪伴 | 選擇貓或狗、名字並確認 → 居家像素小夥伴與迎接 → 短陪伴／排散步 → 出遠門前確認託顧 | 只養一隻；無每日餵食懲罰；短陪伴每週一次心情收益；散步占一天；出發才付 $300 或占用熟人照顧日 |
| 選配小遊戲 | 排對戲接話練習 → 三個無倒數場景選擇 → 完成練習 → 演技結算 | 可中途存讀檔；可略過且仍有基礎成果；完整練習三次後快結算；一天只一次 |
| 跨系統事件 | 真實作客／手作贈禮 → 延遲手機訊息 → 可回覆的對戲邀請 → 排練室實際合作 → 後續記憶；穿搭印象也能進入聯絡回覆 | 必須有來源與當事人；合作練習不冒充正式通告或已完成作品；過期邀請／失和會關閉 |
| 因果與資訊 | 赴約時詢問合照及分享意願 → 同意後私人保存 → 玩家再次確認公開 → 清楚可辨識的公開照片才引起討論 → 可收回原貼文 | 拒絕拍照不影響赴約；私人作客、禮物、未分享照片不曝光；討論不擅自修改正式戀愛狀態；既有討論不因刪文被改寫 |

## 存檔與驗證

- 新增 `cityLife` version 1，核心 hydration 與像素 migration 共用 allowlist 正規化；舊檔補預設，不推定缺失的交往起日、不把舊場景進出紀錄當成已完成熟客日。
- 名字、文字、整數範圍、已知 NPC／衣服、資料長度均驗證；日期上限為五年。跨檔記憶不共用。
- 正式行動沿用每日 ledger；服裝印象、熟客日、短陪伴、照片曝光另有去重。取消未完成行動不發結果；改約先驗證新日期才釋放舊檔期。
- 舊媒體追問也改為需要近期、可辨認並已同意公開的合照來源；同一線索不重複出題。傳聞熱度／模糊回應不再隨機製造偷拍或實錘等級，明確公開確認仍沿用正式回應規則。
- 額外連續 1,820 天城市生活混合壓力檢查：19 次重要日邀約、445 次散步，抵達五年結局，逐日存檔驗證通過（使用充足資金與健康測試條件，不代表平衡性盲測）。
- `tests/phase-two-city-life.test.mjs` 驗證上述規則與整合流程；既有全部測試、五年模擬、世界反應、素材、PWA 和打包檢查照常執行。
- `tests/e2e/pixel-city-life.spec.mjs` 由六種既有瀏覽器／尺寸配置執行：桌機 Chromium、手機 Chromium、平板 Chromium、手機 WebKit、平板 WebKit、Firefox。另將原本只在桌機／手機跑的居家驗收納入相同矩陣。
- 此環境没有本機可用的瀏覽器／agent-browser；不能把 Node 測試當作畫面驗收。瀏覽器結論以本 PR 的 GitHub Actions 結果為準；測試保存赴約、寵物與接話畫面，失敗時上傳診斷。

## 明確限制與後續

- 穿搭仍是現有整套美術，不是可自由拆裝的紙娃娃。
- 本次先深化五個地點；不增加新 NPC、地圖區域、多人社交或交易。
- 沿用一年 52 週／364 日的遊戲時間。12 月 31 日收於年末最後一天；2 月 29 日於 2 月 28 日慶祝；舊檔無交往起始紀錄時不編造紀念日。
- 寵物是簡潔的原創像素輪廓，在家門口或散步時玩家身旁呈現；不是完整動物 AI／尋路與餵養模擬。現有機場日視為外出託顧日，尚無多日桌面旅行系統。
- 先做對戲接話一款。節奏按鍵、綜藝挑戰、雙人料理評估後不納入本次，避免把首版變成多款遊戲合集。略過不鎖主線。
- 照片為帶來源與文字回憶的合照紀錄，不生成新 NPC 合成照片；公開討論接入既有社群／新聞，不擅自更改關係。
- 正式五年職涯、戀愛主線與既有結局仍由原規則控制。Windows／macOS 封裝是第三階段，自備 Key 的 AI 聊天是第四階段，都尚未實作。
