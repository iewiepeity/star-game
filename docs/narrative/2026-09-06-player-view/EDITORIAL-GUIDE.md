# 玩家可見文字規則

這份規則補充前一輪[敘事編輯總綱](../2026-09-06/EDITORIAL-GUIDE.md)，適用像素場景、人物對話、手帳檔案、日結及提示。

| 層次 | 玩家可以看到 | 不應直接顯示 |
| --- | --- | --- |
| 場景觀察 | 當下能看、聽、觸及的景物，以及不預設未來結果的感受 | 碰撞範圍、走位規格、NPC 生成／排除規則、模型或渲染說明 |
| 人物說話 | 符合說話者個性與現場的台詞 | profile.values、speech 寫作指引、弧線大綱、攻略功能說明 |
| 人物檔案 | 公開職業資料、目前關係、實際初遇與共同經歷 | 尚未透露的恐懼、弱點、秘密、未來成長方向與結局提示 |
| 人物關係網 | 已認識人物的共同作品、已發生共同事件、公開圈內消息 | 任意兩人的內部關係強度、未被告知的私交設定 |
| 行程日結 | 今天的活動描述與真實結算；實際相遇另列 | 把「可能遇見某人」當成已發生結果，把功能規劃當成遊玩經歷 |
| 操作提示 | 費用、耗時、解鎖條件、不可操作的原因、真實能力變化、操作結果 | 開發進度、資料欄位／引擎術語、不影響玩家決策的技術細節 |

## 接線原則

1. 觀察物件只讀 `src/pixel/city-interaction-copy.js`，不得回退讀取 gate 或內部規格。
2. 探索日結只讀 `src/pixel/location-day-copy.js` 的敘事。地圖用途提示與結算正文分開；NPC 實際相遇及獎勵由各自紀錄呈現。
3. NPC 作者設定保留在資料層，人物檔案透過明確欄位選擇顯示；禁止整包列出 profile。
4. 信任提高本身不等於玩家聽過全部秘密。未有對話／事件依據時，不把秘密填入檔案。
5. 舊存檔保留原始歷史與數值；已知舊版功能說明只在日結呈現時精準替換，不全面改寫歷史。
6. 審核需走到實際互動與結果畫面。字串存在、測試通過及文法正確，都不能代替玩家視角的閱讀判斷。

## 本次回歸保障

全部25個可觀察物件有獨立正文；26個探索地點日結不再依賴 map.effect/note；11位人物檔案測試禁止作者私密欄位與未來弧線外洩，同時保留已發生回憶與必要操作條件。
