# 玩家視角與內部設定分離修正

日期：2026-09-06。基準：`1ea5f29728c723668f70dfdc2756d84c62365a4d`。核心1.33.1／像素版0.10.1。

這次修正由玩家截圖發現：海邊顯示「角色停在可走岸線，不踏入不可通行的海面」，診所顯示「私密諮詢內不安排無關 NPC 閒晃或突發搭訕」。原因是地點觀察的生活片刻直接讀取 CITY_CATALOG.gate，將製作規格當成了遊戲正文。上一輪敘事改稿與流程驗證漏掉這條顯示路徑。

## 修正範圍

| 入口 | 原問題 | 本次處理 |
| --- | --- | --- |
| 25個地點觀察點 | gate混有碰撞、NPC排程、外型生成、隱藏線開放等開發規格 | 刪除客戶端gate欄位，改用獨立CITY_DETAIL_COPY；逐地點撰寫現場觀察，保留原物件、走位與行動規則 |
| 26個探索地點的日結 | 直接將map.effect/note用途提示顯示為今日成果 | 用獨立日結正文；地圖用途提示不再流入敘事，數值及真實相遇仍依原流程處理 |
| 舊存檔日結 | 已儲存的功能提示仍可能隨結果恢復顯示 | 僅針對已知探索活動與完全相等的舊提示，在呈現時換用新版；歷史、附加相遇與數值保留 |
| NPC初識 | 9位擴充對話的第三句直接拼入profile.values；部分開場假定不符的所在地或玩家仍是新人 | 改為專寫短自介與場景通用開場；銀髮人物不再自曝多周目設定 |
| 人物檔案 | 作者的私下面貌、目標、恐懼、弱點、秘密、成長方向與玩家功能連結直接可見；speech寫作指引當作引言 | 只列公開資料、目前關係、已發生回憶與實際初遇，不因信任數值直接揭露整份私密人設 |
| 人物關係網 | 直接顯示作者設定的私交、未認識對象及精確強度 | 依已知雙方的共同作品、已完成群像事件與公開消息呈現 |
| 一般提示 | 換裝描述渲染實作、晚期玩家仍顯示「剛到星望市」等 | 改為與玩家當下操作有關的文字 |
| 機場 | 已能探索仍顯示系統尚未開放 | 更新公共航廈用途文字；海外條件與原有規則不改 |

海邊的新正文：

> 海風掀起衣角，浪花在岸邊散成一片細白的泡沫。你靠著木棧道的欄杆，讓視線慢慢跟著海面移遠，安靜聽了一會兒潮聲。

診所的新正文：

> 諮詢室的門輕輕闔著，門邊掛著「請輕聲交談」的小牌子。走道旁的候診椅排得整齊，你放輕腳步，沒有往門裡張望。

必要的費用、耗時、能力成果與操作限制仍可見。隱藏作者設定並不代表把遊戲操作資訊一併藏起來，具體判準見[玩家文字規則](EDITORIAL-GUIDE.md)。
