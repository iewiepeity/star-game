# 第二階段文字備查

基準 commit：`b1d8db53b3ecc69f34e4b2340f2200ce8230a452`。本階段採新增情境分支，沒有刪除或覆寫原有角色主線、戀愛台詞、作客正文與手作正文。

因果檢查另修正舊媒體緋聞分支：原檔完整保存於 `originals/media-engine.js.txt` 與 `originals/rumor-engine.js.txt`。原訪談正文「主持人笑著把話題轉向近期網路上的同框討論，現場所有鏡頭都等著你的回答。證據愈完整，亂否認的風險也愈高。」替換為「主持人提起『你公開的咖啡館合照』，兩人的臉都能辨認，於是問了彼此的關係。同框只證明那天一起出現，不代表任何人已經承認交往。你可以決定怎麼回答。」實際程式以 `clue.label` 帶入引述標籤。來源由「訪談前的網路同框討論」改為「玩家主動公開、雙方同意的咖啡館合照」，並保存照片 ID。

原因：沒有公開線索時不應直接編造同框消息。模糊回應、熱度升高與否認本身也不是新證據，因此停止隨機升級證據；真正公開確認仍可形成正式回應紀錄。原本採用更高證據數值的舊存檔不被擅自改寫。既有測試的高證據否認案例改為維持等級 4，仍保留可信度變化驗證，另新增無線索／熱度去偽證回歸。
