# 第一階段：居家生活、作客與手作禮物

## 玩家流程

1. 從像素版選單進入「居家生活」。
2. 家具與材料可直接購買；家具換上、紀念物展示及查看不消耗日期。
3. 作客與手作必須選擇尚未結束的日期，排入七日行程並在住處完成。
4. 手作完成後可保留、自用，或送給已認識的人物。
5. 作客及贈禮會寫入既有 NPC 共同回憶，供後續人物介面與故事引用。
6. 家具與紀念物直接反映在住處場景。角色坐下時的遮擋前景也使用當前布置，原始插畫與碰撞區不變。

## 防重複與資訊界線

- 家具已擁有時不會再次扣款。
- 同一日結算沿用像素版行程 ledger，讀檔或重播不會重複消耗材料、發成品或增加關係。
- 同一 NPC 每週只能從手作贈禮取得一次關係收益；重複贈送同配方時收益降低。
- 作客只開放給已交換聯絡方式且關係足夠的人物；敵意達門檻時拒絕安排。
- 玩家只會看到「還不適合到家裡」等生活語句，不顯示成功率、事件旗標或隱藏骰值。
- 備用鑰匙需要高度親近與信任。關係破裂或交惡後，即使紀錄仍保留，權限也立即失效。
- 鑰匙失效後需由玩家重新交付，不因關係回升而自行恢復。第一階段提供交付／撤回／失效紀錄，不包含 NPC 自主開門、同居或離線 AI。
- 同 NPC 每週只接受一次居家邀約；材料會預留給尚未完成的製作日。改期需先取消舊約定，正式通告與排程助手不會默默覆蓋作客。
- 入圍紀念不標示為得獎。手作品質依現有的學識、時尚、創作能力計算，不引用不存在的技能。

## 存檔相容

舊存檔透過 `hydrateState()` 與像素存檔驗證自動補齊 `homeLife`。新增內容包含家具持有／擺放、材料、成品、紀念物、鑰匙、作客與贈禮紀錄；不修改舊版人物、作品或行程資料。
