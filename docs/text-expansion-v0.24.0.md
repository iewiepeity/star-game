只計正式遊戲 JavaScript 模組依賴中的去重靜態文本，排除程式碼、註解、測試、更新紀錄、素材識別資料及模板動態插值。中文字數不含標點、數字、英文。文本條數包含介面、名稱、短句和敘事，不等於劇情事件數；替換作品名、重播與條件排列組合不算新增。

## 本次新增

- 81 套原創作品後續情境：歌曲／影視／節目各 3 方向 × 發行初期／幾週後／隔年回看 × 每階段 3 套。每套含私人敘事、公開討論、3 則觀眾留言與共作夥伴回應，共 243 則觀眾留言。
- 90 段創作過程及發行變體：草稿 36、製作 27、發行 27；原有 90 段保留。
- 市場表現分層、先前私人回應的延續、依媒介區分的選擇結果，以及自主／公司發行和幕後主創的情境補充。
- 同方向後續情境先輪完 3 套，再循環；創作同段位優先未讀。選取不消耗遊戲 RNG，也不另給獎勵或自動安排工作。
- 修正已發行卡片固定顯示中段範本的問題：優先使用作品保存的實際發行文字；缺少歷史的舊檔按實際分數選取。已完成作品不重複展示企劃示例。

## 舊存檔

已回答的故事不改寫。尚未回答且能辨認創作方向的原創作品回響，在下次週更新時升級；不重複排入同一事件、不重領收入、不改寫既有角色歷史。

網站及安裝版識別不變；像素版號 v0.24.0、核心／離線快取版號 1.47.0。
