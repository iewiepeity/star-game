# 星途未定

純規則版繁體中文娛樂圈五年成長模擬遊戲。玩家從大學畢業後的新人租屋處出發，自訂角色、訓練能力、尋找經紀公司、參加試鏡、完成作品、經營人際與戀愛、面對市場與輿論，最後依五年留下的作品、獎項、關係、財產與公眾位置進入結算。遊戲不需要 AI／API Key，也不需要登入；GitHub Pages 開啟後即可在瀏覽器單機遊玩。

## 現行版本核心

### 五年是五章人生，不是 260 次同一週

1. **Year 1｜活下來**：能力、錢與第一份履歷都不足，先站穩新人期。
2. **Year 2｜我是誰**：開始建立歌手、演員、綜藝、商業或全能等職涯輪廓。
3. **Year 3｜位置有限**：同期、競爭者、榜單、獎季與資源比較開始變得具體。
4. **Year 4｜選擇有代價**：商業、作品、健康、感情與自主權互相衝突。
5. **Year 5｜留下什麼**：代表作、長期關係與最終選擇收束成五年答案。

每年都有可見目標與壓力；中後期不只提高數值，而會改變玩家正在面對的問題。

### 75 份工作採 A／B／C 深度

通告總數維持 **75 份**，不靠無限加工作解決重複感。

- **50 份 C 級基礎工作**：完整試鏡、簽約、製作、完成、違約與履歷流程。
- **10 份 B 級特色工作（J051～J060）**：各有至少兩段專屬製作事件與作品自己的公開回聲。
- **15 份 A 級旗艦工作（J061～J075）**：專屬開工、危機、關鍵抉擇、完成、宣傳與長尾，是中後期代表作候選。

正式工作必須依指定工作日排入行事曆，期限內未完成會違約；試鏡的選擇、身心狀態與情報會實際影響結果。

## Playable Depth Pass｜實玩深化

第二輪 1～16 深化不增加主要 NPC、地點或通告總數，改為讓既有內容更有連續性、後果與重玩差異。

### 一週會形成故事

每週會依目前狀態形成工作、訓練、戀愛或輿論主線。週初提示、當週事件與週末結算會引用同一件事，不再把七天視為互不相干的 Action。

### 小選擇會跨週回來

短篇事件鏈採真正的玩家選擇：第一段 A／B 決定後，數週後會出現第二段，最長可在一年後再次回收。事件不會在一次結算後消失。

### 工作有合作班底

重要作品會建立導演、製作人、編劇／搭檔、攝影、造型或音樂製作人等非攻略工作角色。後續作品可能再次遇到同一批人，合作次數與信任會累積，因此「業界記得你」不只存在於數值。

### 試鏡不是即時成功／失敗按鈕

正式試鏡目前包含：

- 試鏡前情報與團隊偏好。
- 現場可能追加的臨場要求。
- 正式排入一天行程後才執行。
- 落選會留下試鏡記憶。
- 一段時間後可能收到同一組人的回邀，實際解除重試冷卻，而不是只跳一則文字。

### 失敗也是路線

落選、失誤與獎項失利可以形成後續機會、業界印象與再邀約。失敗仍有代價，但不等於單純浪費一格時間。

### 第三年之後真的有競爭

既有 competitor／rival 系統會在中後期被搬到玩家眼前。同檔作品、聲勢與獎季比較會形成可見事件，玩家可選擇把注意力放回作品或正面搶市場位置。

### 作品會變成人生履歷

作品除了星等與品質，還會保存 legacy tags，例如：

- 突破作
- 影評口碑
- 商業代表作
- 獎季作品
- 全民名場面
- 爭議作品
- 轉型作

作品同時保存合作班底；娛樂圈週報會直接引用這些履歷，而不是把作品做完後收進圖鑑就結束。

### NPC 會記共同經歷

共同記憶目前可保存第一次見面、第一次合作、第一次約會、第一次真正衝突、公開關係、分手、復合、訂婚與結婚等里程碑。後續人物文本與週報可以引用這些記憶，而不只依靠好感數字。

### 戀愛會跟工作互撞

地下戀／公開戀若同時有正式工作，可能遇到炒 CP、宣傳尺度、紅毯與媒體追問等事件。玩家可以保護關係、把工作與私生活分開，或配合宣傳效果；選擇會影響關係與話題。

### 經紀人會主動踩煞車

過勞、健康惡化或連續作品表現不佳時，經紀人可主動介入，而不是只提供 bonus。玩家可以接受安排、堅持原計畫或協商折衷，並承擔各自的疲勞、信任與曝光後果。

### 爆紅會改變普通生活

高知名度不再只增加工作邀約。隨人氣上升，公開場所會逐漸出現被認出、合照、偷拍、即時貼文與額外疲勞；爆紅後普通出門本身就可能成為公開行程。

### 炎上是跨週危機

實際醜聞引擎支援正式說明／承擔、暫不回應、明確否認、模糊處理；緋聞且已有伴侶時還可直接公開關係。聲明後第 1 週、第 3 週仍可能出現後續影響，品牌與合作方會記住處理方式。

### 年度大型事件會提前倒數

春季平台招商、城市電影節、夏季大型音樂祭、時尚週、年度盛典／獎季與跨年舞臺會提前數週進入視野。玩家能提早保留檔期或照原節奏衝，正式週再進入大型事件選擇。

### 二周目繼承的是「懂這個世界」

二周目不繼承能力、金錢、作品與關係數值。玩家可選擇保留：

- 曾經認識 NPC 的眼熟印象。
- 前輪代表作品類型／legacy 所形成的職涯知識。
- 特定時機出現的「直覺」提示。

因此重玩有資訊優勢，但仍必須重新成長。

### UI 以實玩使用資料收斂

遊戲會記錄玩家實際開啟各 App 的次數，作為後續介面精簡依據；首頁仍維持「現在最急／有人找你／本章目標」三層，不把所有後台數值塞在第一畫面。完整世界資訊集中到娛樂圈週報。

## NPC 與世界

目前維持 **10 位主要 NPC**。每位都有背景、公開形象、私下面貌、動機、恐懼、價值觀、人物弧線、三章人物主線與七類專屬相處事件。

NPC 不需要玩家點開才會活著：他們會自行接作品、失利、休息、轉型或累積聲勢，變化會出現在週報／社群；如果玩家已經認識該 NPC，部分近況會自然進入私人訊息。陌生 NPC 不會因此憑空進通訊錄。

感情狀態支援 `none → interested → ambiguous → dating → committed → engaged → married`，並包含拒絕、分手、復合、地下戀、公開戀情與唯一伴侶限制。

## 經紀公司

目前四間公司：星光藝能、映界文化、澄音娛樂、浪潮媒體，各自有固定經紀人與職涯偏好。

支援資格比對、投遞、面談排程、面談選擇、正式合約、抽成、新人任務、經紀人推薦工作、合約末期續約談判與到期後重新投遞。四位經紀人各有保守、進取、危機處理與續約立場。

## 行程、健康與地圖

每週七格、每日一個主要安排；包含訓練、自由活動、試鏡、正式工作、人物活動、創作、社群、經紀人／公司面談等。

行程頁會顯示通告剩餘場次與指定工作日、期限衝突預警與疲勞趨勢，不公開精確成功骰值。疲勞、體力、健康與心情會共同影響訓練、試鏡、探索與工作品質；極端過勞可能住院或進入過勞結局。

星望市維持 **26 個地點**。本階段不擴點，改用平／假日氣氛、NPC 工作線索、產業徵選、身體狀態與知名度摩擦深化同一張地圖。

## 作品、創作與獎項

正式通告完成後建立作品履歷。三星以上且品質達標的作品先進入獎季候選，年度典禮週才進行入圍／得獎判定。

創作工作室提供三類企劃 × 三種創作方向，可選公司共同製作、販售企劃權或自主製作／發行；成品有品質、星級、市場分數、收益與長尾回聲。

## 社群、論壇與娛樂圈週報

- 星光社群可發文、按讚與回覆已認識 NPC。
- 星談論壇依近期工作、人氣、競爭與爭議形成話題。
- 娛樂圈週報集中顯示市場、作品生命週期、作品 legacy／班底、NPC 職涯、競爭者、品牌、經紀人壓力、共同記憶與跨週事件鏈。

重大作品與違約也會留下 world echo，之後可再次進入週報、社群、論壇、人物訊息或可見事件。

## 存檔、離線與多周目

目前 save schema 為 **v14**。

- 自動存檔。
- 五個手動槽。
- 讀檔前備份。
- JSON 匯出／匯入。
- 舊版逐版 migration＋`hydrateState()` 正規化。
- v14 保存週故事、跨週事件鏈、工作班底、試鏡記憶、作品 legacy、人物共同記憶、經紀人介入、年度事件、二周目知識與 UI telemetry。

提供 Web App Manifest 與 Service Worker；首次完整載入後可安裝並離線啟動。

五年結束或主動退圈後會建立不可變結局快照。二周目可選擇「眼熟＋直覺」繼承；沈霧棠仍是多周目隱藏路線。

## 技術架構

專案採純瀏覽器 ES Modules：

```text
src/data/*   → 內容與設定
src/core/*   → state、存讀檔、RNG、工具
src/logic/*  → 規則與狀態變化
src/views/*  → state → HTML
src/bind/*   → UI 事件
render.js    → 唯一重繪入口
main.js      → 開機入口
```

完整不變量、每週世界推進順序與深化層說明見 [`ARCHITECTURE.md`](./ARCHITECTURE.md)。第一輪垂直深化驗收見 [`DEEPENING-1-16.md`](./DEEPENING-1-16.md)；第二輪實玩深化定義見 [`PLAYABLE-DEPTH-1-16.md`](./PLAYABLE-DEPTH-1-16.md)。

## 本機執行與測試

```bash
npm install
npm run validate
npm test
npm run simulate
npm run test:e2e
```

`npm run simulate` 會以 10 種玩法 archetype 跑完整 260 週，檢查中後期破產、健康失衡、無作品、週故事覆蓋與過度單一行為。CI 另用 Playwright 跑桌機與手機流程。
