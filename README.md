# 星途未定

純規則版的繁體中文娛樂圈成長模擬遊戲原型。

目前包含角色姓名與性別自訂、21 項公開能力依定案公式（30＋2D60，另含 3 項天賦＋1D80、2 項弱項－1D30）擲骰、首次免費＋3 次免費重骰、隱藏特質與娛樂圈評價初始值、以 1,000 為滿值的能力條、週行事曆排程、通告一鍵排定，以及逐日執行結果。

目前 UI 採柔和水彩手繪風格，主畫面是玩家的新人租屋處；行程、能力、人際與紀錄都在桌上的平板中操作。點選平板行事曆日期後，會在平板內開啟活動選單。

遊戲已加入初始存款、課程費用、知名度、粉絲、簽約進度、每週任務與三種本週策略。試鏡、街頭演出及自由活動會出現現場選擇；不同選項會改變成功率、收入、能力、人脈或曝光結果。七天完成後會依任務條件提供週結算與獎勵。

通告會標示指定工作日（例如每週一、二、三）與資質需求門檻，「一鍵排定」會優先把工作排進指定工作日。人物檔案只會列出玩家實際認識過的人物，尚未相遇前不會出現在列表中；介面改用與整體水彩風格一致的卡片設計，取代先前的深色終端機風格。人物檔案已加入好感、信任與戀愛狀態欄位，可用測試按鈕培養感情並觀察戀愛狀態推進。

疲勞超過 100 會強制住院一週（本週剩餘行程取消），超過 200 會觸發過勞死亡並直接進入結局畫面。房間畫面新增「結束這一輪」測試入口，對應主動退圈；結局畫面會總結能力、事業、戀愛、人脈與財產，並可選擇是否啟用「認識繼承」，繼承後下一輪重新遇到同一位 NPC 會有眼熟加成。重要事件（例如初次認識 NPC、戀愛狀態推進）會記錄為旗標，顯示在星途紀錄頁。

本版本不使用 AI，也不需要 API Key。
