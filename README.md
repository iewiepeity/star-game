# 星途未定

## 核心引擎里程碑（v0.6）

遊戲維持純單機網頁架構：每位玩家從 GitHub Pages 開啟後，各自在自己的瀏覽器遊玩，不登入、不連線競賽，也不共用進度。Supabase 並非執行必要條件。

- 75 份通告已接入共用多通告狀態機，支援同時登記、把正式試鏡排入某一天、簽約、指定工作日排程、逐次執行、完成與違約。
- 完成通告會建立作品履歷，依類型、星級與品質累積職涯方向；三星以上作品可進入獎項入圍／得獎判定。
- NPC 關係統一由人物引擎處理初遇、友情、信任、隱藏好感、關係階段及人物里程碑，事件不再直接散落修改人物狀態。
- 通用事件引擎支援條件、旗標、選項與效果，並將事件分類為即時、選擇、延遲、連鎖、人物、職涯及輿論事件。
- 五年／退圈／過勞結局會依作品、獎項、職涯路線、關係、財產、知名度、粉絲及公眾評價綜合判定。
- 存檔格式升級至 v12：自動存檔、五個手動槽、讀檔前備份、JSON 匯出／匯入及舊版遷移；舊存檔會自動補齊 NPC 交惡與相處記憶欄位。
- 提供 Web App Manifest 與 Service Worker；首次完整載入後，可安裝並離線啟動。
- `npm test` 執行核心引擎測試，`npm run validate` 驗證所有內容資料與素材完整性。

純規則版的繁體中文娛樂圈成長模擬遊戲原型。程式碼在 `src/` 底下依 data／core／logic／views 分層模組化，各檔案職責與模組間串接方式見 [ARCHITECTURE.md](./ARCHITECTURE.md)。

目前包含角色姓名與性別自訂、兩男兩女共四款玩家立繪、紙娃娃換裝衣櫃、21 項固定公開能力各自 0～150 隨機擲骰、無限重骰、隱藏特質與娛樂圈評價初始值、以 1,000 為滿值的能力條、週行事曆排程、通告一鍵排定，以及逐日執行結果。隱藏特質不直接顯示數字，只會透過事件與人物反應逐步揭露。

通告內容庫現有 75 份資料，涵蓋歌曲、電影、電視劇、綜藝與廣告，並分布於一至五星。每份均包含資質門檻、軟性特質、試鏡地點與情境、兩種現場選擇、指定執行日、場次、期限、報酬及成長獎勵；一星門檻也高於多數開局平均值，玩家仍需先訓練。正式試鏡不會在信箱中立即結算，必須先選擇空檔排入行事曆，跑到當天才呈現選擇與結果。Supabase 的安全唯讀 schema 與種子產生器位於 `supabase/`。

角色建立時可自訂姓名與性別／稱呼；女性與男性各自鎖定對應立繪，非二元與自訂稱呼可自由選擇四款外型，之後能在星望整形外科付費變性。四款立繪皆準備新人私服、練習服、試鏡造型、舞台造型與典禮禮服五套完整圖像，部分髮型也會隨場合改變；每位角色的衣服分開購買，不會因切換立繪而共用。服裝提供暫時性公開能力加成，例如新人私服增加親和力與時尚、練習服增加舞蹈與肢體表現、試鏡造型增加鏡頭感與口才、舞台造型增加鏡頭感與時尚、典禮禮服增加氣質與儀態。加成會實際套用至能力頁、通告資質、試鏡、經紀公司資格及面談判定，但不會永久灌入基礎能力。銀灰角色已改列為尚未登場的 NPC，不再是玩家可選立繪，也不會在尚未相遇時出現在通訊錄。

目前 UI 採柔和水彩手繪風格，主畫面是玩家的新人租屋處；行程、能力、人際與紀錄都在桌上的平板中操作。行程規劃頁的活動選單常駐在同一頁，不必點進某一天才會跳出來：選單上方會標示「接下來排入」的目標日（游標），點選單裡的活動就直接套用到那一天並自動把游標移到下一天；排到星期日後游標會停在最後一天，不會繞回星期一覆蓋既有行程。也可以先點行事曆上的某一天，把游標移過去後再開始排。

遊戲已加入初始存款、課程費用、知名度、粉絲、簽約進度、每週任務與三種本週策略。疲勞、體力、健康與心情會共同修正訓練效率、試鏡、面談、街頭演出與正式通告品質；介面只顯示狀態與文字機會，不揭露精確骰值。七天完成後會確實依「訓練兩次、工作一次、疲勞不高於 60」判定週任務與獎勵。

平板新增「星途成就」，目前包含旅程、成長、工作、職涯、創作、人際與生活類成就；支援隱藏成就、解鎖週次、進度條與未讀徽章，資料會隨本機存檔匯出及匯入。NPC 主動訊息已接入手機通訊錄，點開人物後會標記為已讀。

星望市地圖目前開放 21 個自由探索地點，涵蓋演藝、訓練、靈感、生活、休閒與健康分類。每個地點都有獨立能力／狀態效果；選擇「主動探索」較容易觸發 NPC 初遇，選擇「專注體驗」則取得額外能力成長。每一天的目的地分開保存，同一週可前往不同地點，複製上週時也會連同各日目的地一起複製。國際機場保留給後續外地發展系統。

人物內容目前有 10 位主要 NPC，職業橫跨主持人、導演、歌手、演員、時尚總監、綜藝製作人、經紀人與攝影師。每位皆具備成長背景、職涯、公眾形象、私下面貌、動機、恐懼、價值觀、優缺點、生活習慣、未公開經歷、人物弧線及玩家劇情鉤子。聊天、吃飯、工作應援、合作交流、深入關心、約會與和解七類行為均有各角色專屬情境，共 70 組事件；聊天另有會踩中各人物價值底線的交惡選項。事件排入週行程後會在當天顯示人物半身圖與選擇，結果寫入相處記憶並影響友情、信任、隱藏好感及隱藏敵意。好感及敵意的升降只以立繪旁短暫飄出的愛心、心裂、閃電與緩和符號提示，不顯示精確數字。敵意可進入心有芥蒂、關係不合、交惡與宿敵，並限制私下往來、戀愛、人脈推薦及合作；和解必須透過人物專屬事件逐步修復。九位已配置一般或條件式戀愛路線，秦紹謙現階段維持職涯夥伴線；銀灰角色保留為後續多周目隱藏線。人物列表與社群使用 320×320 頭像，人物檔案與逐日相處事件使用 480×640 半身圖，玩家需要時才切換完整全身圖；三者皆為 WebP 並使用延遲載入，避免立繪造成長時間白畫面。

隨機事件採獨立資料池：22 個地點（21 個已開放地點與 1 個預留機場）各有 10 則專屬事件，共 220 則；17 種可排行程各有 5 則，共 85 則。事件會隨機改變能力、隱藏特質、心情、疲勞、金錢、知名度、粉絲、業界評價或人物關係，同一地點／日程不會連續抽到同一則。自由活動選擇「主動探索」才可能讓尚未認識的 NPC 透過事件正式登場，選擇「專注體驗」不會讓陌生人物憑空進入通訊錄。

平板新增「星談論壇」與「星光社群」。論壇會依玩家姓名、近期行程、知名度、粉絲與爭議度生成玩家相關話題，討論串可點入閱讀並重新整理模擬網友回覆；社群可發布訓練打卡、日常分享與工作預告，按讚官方／已認識 NPC 的動態，並依玩家人氣模擬按讚與留言。兩者皆採本機規則與文字模板，不呼叫 AI。

通告會標示指定工作日（例如每週一、二、三）與資質需求門檻，資質區會並列玩家目前值與需求值；通告只能排入指定工作日，指定日沒有空檔時會要求玩家先調整行程。試鏡會依能力、隱藏特質與現場選擇判定，不再固定通過。人物檔案只會列出玩家實際認識過的人物，尚未相遇前不會出現在列表中；介面改用與整體水彩風格一致的卡片設計。友情、信任與戀愛好感分開計算，其中好感與信任不顯示精確數字，只用相處感覺與行為跡象提示；關係可經人物事件進入在意、曖昧、交往、穩定伴侶、訂婚與結婚，正式關係另支援地下戀、公開、分手及唯一伴侶限制。

疲勞超過 100 會取消本週剩餘行程並強制完整住院休養一週，超過 200 會觸發過勞死亡並直接進入結局畫面。房間畫面新增「結束這一輪」測試入口，對應主動退圈；結局畫面會總結能力、事業、戀愛、人脈與財產，並可選擇是否啟用「認識繼承」，繼承後下一輪重新遇到同一位 NPC 會有眼熟加成。重要事件會記錄為旗標，顯示在星途紀錄頁。

平板首頁新增「經紀公司」入口（未簽約時即原本的簽約準備度卡片，點擊可直接開啟）。經紀公司資料集中放在 `AGENCIES`，目前提供星光藝能、映界文化、澄音娛樂與浪潮媒體四條路線，分別偏向綜合培養、影視演員、音樂偶像及綜藝新媒體；各自具有不同門檻、期間、抽成、創作自主與保證試鏡。每間公司都配置一位固定經紀人，經紀人的工作方式會實際影響每週邀約數量、邀約保留期限與推薦通告的試鏡準備加成，簽約頁也會整理本週邀約、迫近期限、疲勞健康及輿論風險，但不會擅自替玩家排入行程。玩家可在經紀公司頁查看公司資料、比對自己目前數值與門檻（符合／未達），投遞新人資料。符合資格前按鈕會停用並列出還缺什麼；投遞後可將「經紀公司面談」一鍵排入本週行事曆的空檔（沒有空檔則提示先騰出行程），面談當天會用逐日事件呈現「穩健回答」與「展現企圖心」兩種選擇。面談的成功率文字提示由 `deterministicInterviewScore()` 純函式計算（只依能力、隱藏數值、心情、疲勞與回答方式，不含亂數），同一次面談不論重新整理畫面幾次都會顯示相同提示；真正是否成功要到結算當下才擲一次骰，不會事先算死結果，介面也只顯示「幾乎不可能／希望渺茫／值得一試／勝算不錯／十拿九穩」等文字，不顯示精確機率。面談完成或取消後，當天的行程欄位會立即改回休息，不會被複製上週或跨週沿用而重複觸發結果；若面談排定日之前因疲勞過高強制住院，`cancelAgencyInterview()` 會統一取消面談、把申請狀態退回「已投遞」並清空行程欄位，玩家之後可以重新安排，不會卡住。

面談通過會產生正式合約，玩家可查看合約條件後選擇接受或婉拒；接受後身分列會顯示「所屬公司・旗下新人」，經紀公司頁改為顯示合約起訖週、剩餘週數與抽成，首頁與週結算不再出現「簽約準備度」，本週任務也改為「公司新人任務」（獎勵改為金錢與業界評價），且無法再投遞其他公司；婉拒則維持未簽約，不會重複收到同一份合約。合約到期後（`checkAgencyContractExpiry()` 於每週開始時檢查）會自動停止抽成、清除目前簽約公司並恢復「自由藝人」身分，但會保留一筆歷史紀錄與星途旗標，經紀公司頁會顯示「合約已到期」，並標示續約／另尋公司為後續開放功能。簽約後正式通告（例如晨露汽水廣告）結算會套用公司抽成，結果會列出通告總額、公司抽成與玩家實領；未簽約或合約已到期時抽成一律為零，`calculateJobIncome()` 會實際檢查合約是否仍在有效期間才計算抽成，而不是只看「是否曾經簽過」。

本版本不使用 AI，也不需要 API Key。

## 立繪載入最佳化

每款立繪保留內部名稱供資料管理，但玩家介面只顯示人物圖像與選取狀態，不顯示內部命名。列表與頭像使用 160×320 縮圖並延遲解碼，畫面中央才載入 512×1024 完整立繪；換裝前會先完成圖片預載，避免整頁白屏。
